# Future Expansion Strategy: The "Swiss Army Knife" Architecture

This document outlines the professional roadmap for evolving ParFix from a single utility into a modular "Master Utility Container".

## 1. Architectural Philosophy
We have refactored the codebase into a Modular Architecture (`app/core`, `app/managers/`). This is the foundation for the "Swiss Army Knife" strategy.

*   **Goal:** To add high-value *utility* modules without bloating the core or causing instability.
*   **The Rule:** Only add *file manipulation utilities* (Renamers, Optimizers, Inspectors). Do NOT add heavy *services* (Media Servers, Databases) which belong in separate containers.

## 2. The "Single Unified Image" Strategy
To keep deployment simple and powerful, we will use a **Single Unified Docker Image**.
- All tools and apps will be included in one image.
- We will use multi-stage Docker builds to keep the image size minimal by only copying necessary binaries.

## 3. The "Apps Dashboard" Pattern
New features will be implemented as modular "Apps" accessible via the **Apps Grid** in the sidebar. This keeps the main interface clean while allowing infinite expansion.

### Implemented Apps:
1.  **GitHub Release Manager**
    - Download assets from any repo.
    - Publish releases/assets to GitHub.

## 4. Potential Future Apps (Illustrative Examples)
These are *examples* of what could be built using this architecture. They are not currently implemented.

1.  **Subtitle Manager** (Example)
    - Auto-download subtitles for selected movies.
    - Extract subtitles from MKV containers.

2.  **Remuxer / Optimizer** (Example - using FFmpeg)
    - Convert `.avi` to `.mp4` (Direct Stream Copy).
    - Strip unwanted audio tracks (e.g., remove Commentary tracks to save space).

3.  **Checksum Verifier** (Example)
    - Generate `SFV` or `MD5` hashes for archiving.
    - Verify file integrity before upload.

4.  **Dedupe / Cleaner** (Example)
    - Find and delete "sample" files.
    - Remove empty folders.
    - Find duplicate files by hash.

## 5. Implementation Guide for New Apps
To add a new app (e.g., "SuperTool"):
1.  Create `app/managers/supertool.py`.
2.  Add routes in `app/routes.py` (`/api/apps/supertool/...`).
3.  Add a card to the "Apps Grid" in `templates/index.html`.
4.  Add a view container `<div id="view-supertool">` in `templates/index.html`.

This strategy ensures ParFix remains professional, scalable, and unbreakable.
